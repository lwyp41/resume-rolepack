# 示例公司A 产品运营实习

> **本文件是格式示例，内容全部虚构。**
> 使用时在 `经历库/` 下新建你自己的文件，并在 `经历索引.md` 里登记一行。

核心工作是围绕新用户首周留存做活动运营与数据分析。独立负责 3 期活动，覆盖约 N 名新用户。

---

**工作内容**

**活动策划与执行**
独立负责 3 期新用户引导活动的方案设计、上线配置与效果回收，涉及文案、落地页与推送时机三个变量。

**数据分析**
用 SQL 提取活动期间的行为数据，按渠道 × 版本拆分，输出首周留存与关键路径转化对比。
所有图表用 Excel 独立制作，结论同步至周报。

**A/B 测试**
对推送时机设计 A/B 对照，实验组与对照组各约 N 人，观测 7 日留存差异并给出上线建议。

---

**使用的工具**：SQL、Excel、内部 A/B 实验平台、飞书多维表

**可追问细节**
- 3 期活动的样本量分别是多少、怎么分组的
- 留存提升是相对提升还是绝对提升、观测窗口多长
- 你在方案设计中独立决策了哪部分
